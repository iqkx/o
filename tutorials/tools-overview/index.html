各工具详细使用方法

1. 二维码生成器

功能：将文本、网址、联系方式等内容转换为二维码图片。

使用步骤：

  1. 在左侧输入框中输入要生成二维码的内容
  2. 拖动尺寸滑块调整二维码大小（128-512像素）
  3. 右侧实时预览生成的二维码
  4. 右键点击图片选择"保存图片"即可下载

使用场景：网址分享、名片二维码、活动报名、支付链接、WiFi密码分享等。

2. 密码生成器

功能：生成高强度的随机密码，支持自定义长度和字符类型。

使用步骤：

  1. 拖动滑块设置密码长度（8-64位）
  2. 勾选需要包含的字符类型（大写、小写、数字、符号）
  3. 点击"生成密码"按钮
  4. 点击"复制"按钮将密码复制到剪贴板

安全建议：建议使用16位以上密码，包含所有字符类型；不同网站使用不同密码；定期更换重要账号密码。

3. 字数统计

功能：实时统计文本的字数、字符数、单词数、段落数等。

使用步骤：

  1. 将文本粘贴或输入到文本框中
  2. 下方8个统计卡片实时显示结果
  3. 包括总字符数、不含空格字符数、中文字数、英文字母数、数字字符数、单词数、行数、段落数

使用场景：作文字数统计、文案长度控制、翻译工作量估算、SEO标题描述长度检查等。

4. 颜色选择器

功能：颜色拾取、HEX/RGB/HSL格式转换、渐变色生成。

使用步骤：

  1. 点击颜色选择器选取颜色，或点击预设色板快速选择
  2. 下方显示HEX、RGB、HSL三种格式，点击"复制"即可复制
  3. 渐变色区域选择两个颜色，实时预览渐变效果
  4. 复制生成的CSS渐变代码

5. Base64编解码

功能：文本与Base64编码之间的相互转换。

使用步骤：

  1. 选择"编码"或"解码"模式
  2. 在输入框中粘贴文本或Base64字符串
  3. 点击"开始编码/解码"按钮
  4. 点击"复制结果"复制输出内容

注意：Base64是编码不是加密，不要用于保护敏感信息。

6. 时间戳转换

功能：Unix时间戳与日期时间的相互转换，实时显示当前时间戳。

使用步骤：

  • 顶部实时显示当前时间戳，点击可复制
  • 时间戳转日期：输入时间戳，点击转换
  • 日期转时间戳：选择日期时间，点击转换

7. JSON格式化

功能：JSON数据的格式化、压缩、转义。

使用步骤：

  1. 在输入框中粘贴JSON数据
  2. 点击"格式化"美化输出，"压缩"减小体积，"转义"生成字符串
  3. 格式错误时会显示具体错误信息
  4. 点击"复制"复制结果

8. 单位换算

功能：长度、重量、面积、数据存储等单位的相互换算。

使用步骤：

  1. 选择换算类别（长度/重量/面积/数据存储）
  2. 输入数值，选择源单位和目标单位
  3. 结果实时显示

9. Markdown预览

功能：Markdown文本的实时预览和HTML转换。

使用步骤：

  1. 左侧输入Markdown文本
  2. 右侧实时显示渲染效果
  3. 可复制Markdown源码或生成的HTML

10. 正则测试器

功能：正则表达式的在线测试，支持匹配高亮和替换。

使用步骤：

  1. 输入正则表达式和标志（g/i/m）
  2. 在测试文本框中输入要测试的内容
  3. 匹配部分会高亮显示，下方显示匹配数量和结果
  4. 可输入替换文本查看替换效果
  5. 提供常用正则模板（邮箱、手机号、URL等）一键填入
